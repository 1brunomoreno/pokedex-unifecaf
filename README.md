# Pokédex Clássica

Aplicação front-end que consome a [PokéAPI](https://pokeapi.co/) e exibe cards dinâmicos dos 151 Pokémon da 1ª geração.

## Tecnologias
- HTML5
- CSS3 puro (Grid, variáveis CSS, media queries)
- JavaScript puro (fetch, createElement, appendChild, localStorage)

## Funcionalidades
- Cards criados dinamicamente via JavaScript
- Busca por nome em tempo real
- Favoritos salvos no navegador
- Layout responsivo
